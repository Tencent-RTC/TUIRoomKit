## [7.1.3] - 2026-11-18

### 新增

- `RoomKitJoinOptions` 新增 `mediaPreference`（`preferMicrophoneOn` / `preferCameraOn`），进房后按偏好打开设备；房间开启全体静音或全体禁画时跳过对应设备（主持人与管理员除外），大房间全体静音时进房不再占用上行音视频位。
- 房间聊天上翻时显示新消息条数提醒，教育场景已开启。
- 教育场景聊天区新增老师移出学生、授予与收回白板权限的提示。

### 变更

- 教育场景课堂计时以预约开始时间为准，提前进入的课堂在预约时间到达前不显示计时。
- 教育场景老师关闭学生麦克风或摄像头、移出学生后不再弹出 Toast；学生进入课堂时老师端不再弹出 Toast。
- 奖杯庆祝消息改为仅发送给在线成员，重新进房或刷新页面不会重放。
- 教育移动端聊天输入框占位文案按课堂类型区分，全体禁言时提示老师已关闭学生聊天。
- 1v1 课堂不再展示全体静音与全体禁言。

### 修复

- 修复再次授予白板权限后，学生无法擦除之前笔迹的问题。
- 修复 Safari 下白板打开时无法开始屏幕共享的问题。
- 修复白板工具栏不跟随 RoomKit 语言的问题。
- 修复教育场景离开课堂消息偶现未发送到聊天区的问题。
- 修复教育 H5 键盘遮挡聊天输入框、iOS 输入时竖屏被识别为横屏，以及 iOS Chrome 横屏两侧安全区重复留白的问题。
- 修复教育场景白板授权状态图标与英文成员列表列宽的问题。

## [7.1.2] - 2026-11-13

### 新增

- 教育场景支持小班课（1v6），PC 与移动端可用，支持全体静音、全体禁言和进出课堂消息。
- `setUIConfig` 新增 `widgetVisible`，可隐藏内置工具栏按钮，会议与教育场景均生效。

### 变更

- 屏幕共享与白板默认推流码率调整为 5000 kbps；预约时长改为 15/30/45 分钟、1/2/3 小时。
- 会中人数改用后台 `participantCount`；默认会议或课堂名称中的用户名只保留前 10 个字符。
- 教育场景视频格子去掉授权边框；退出课堂后不再重置虚拟背景。

### 修复

- 修复教育场景加载白屏、学生端露出共享设置、屏幕共享时成员列表布局被切换，以及进出课堂消息发送的问题。
- 登录超出套餐日活上限（72000）时提示升级；房间操作失败按错误码提示。
- 修复教育移动端布局、白板撤销重做、按钮图标对齐和 Tab 焦点框等界面问题。

## [7.0.0] - 2026-10-23

### 新增

- 正式发布 `@tencentcloud/roomkit-web-vue3` v7.0.0 npm 包，基于 `atomicx` State 层全新重构的 Vue 3 会议 UI 组件库，提供 ESM 与 CJS 两种构建产物及完整 TypeScript 类型声明。
- 新增基于类的命令式核心 API：`RoomKit`，提供 `RoomLayoutTemplate`、`ExitReason` 及强类型的 `RoomKitJoinOptions` / `RoomKitEventMap`。
- 新增 `ConferenceView` 场景视图，PC 与移动端（H5）开箱即用。
- 支持完整会中能力：视频布局切换、摄像头/麦克风设备管理、屏幕分享、会中聊天、成员管理、会议预定、云端录制、实时字幕（转写）、互动白板、小窗模式、视频特效。
- 新增会前组装能力：`SchedulePanel`、`ScheduledListPC` / `ScheduledListMobile`、`MeetingDetailMobile`、`SettingsDialogPC`、`AudioDeviceMenu`、`VideoDeviceMenu`、`LanguageButton`、`ThemeButton`、`useDeviceFault`。
- 新增主题（`ThemeName`）、国际化（`i18n` / `t` / `useI18n`）、UI 配置（`RoomKitProvider` / `setUIConfig` / `useUIConfig`，支持图标覆盖）及全套 `TUI*` 基础组件。

### 变更

- 语义化版本跃迁：v7.0.0 取代已废弃的 v6.x 版本线（`@tencentcloud/roomkit-web-vue3` ≤ 6.2.x）。对外 API 与 v6.x 不兼容。
